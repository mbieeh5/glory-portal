# Glory Platform

**rrafproject ecosystem**

## Overview

**Glory Platform** is a unified web application built under the **rrafproject ecosystem**.
This platform consolidates multiple previously independent applications into a single, integrated system.

Previously, the system was split across several web apps:

* **GloryBank**
* **GloryService**
* **GloryRekap**
* **GloryInvoice**

All of these applications have now been **merged into one large-scale web application**, designed to centralize data, streamline workflows, and simplify long-term maintenance.

---

## Why the Merge?

The unification was driven by several core goals:

* Eliminate duplicate and inconsistent data
* Centralize business workflows
* Improve scalability and maintainability
* Establish a single source of truth across the system

---

## Core Modules

### 1. Customer & Service Management

*(Formerly GloryService)*

* Customer data management
* Service/job records
* Service status tracking
* Customer service history

### 2. Financial & Banking

*(Formerly GloryBank)*

* Income and expense tracking
* Cashflow monitoring
* Financial data integration with reports
* Consistent financial records across modules

### 3. Reporting & Recap

*(Formerly GloryRekap)*

* Daily, weekly, and monthly reports
* Centralized financial summaries
* Real-time data pulled from service and banking modules

### 4. Invoice Management

*(Formerly GloryInvoice)*

* Integrated invoice generation
* Automatic invoice creation based on service data
* Invoice history and payment status tracking

## Security

**rrafproject SEC v1.0**

This application follows the initial security standard defined under **rrafproject SEC v1.0**, which includes:

* Centralized access control
* Role-based data access (where applicable)
* Secure database relations
* Reduced attack surface by eliminating cross-app data sync
* Controlled data flow between internal modules only

Further security improvements and standards will be introduced in future versions.
